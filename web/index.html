          MAKE IT YOUR COACH
          Settings
          Preferences stay on this device. Analysis runs entirely locally by default; the optional AI coach sends a text summary (never screenshots) to the gateway you configure.
          Voice & cadence
          “Local” voices run on the device. Other installed voices may use a speech service. Route browser audio to headphones in Windows.
          If analysis takes longer, the app processes the newest frame next rather than building a queue.
          Advice categories
          The player profile never leaves this browser. Manage it on the Player page.
          Counter suggestions use correlational data. They are not guaranteed hero-specific builds.
          Off by default. No screenshots are uploaded. Export or delete your recording in Replay lab.
          AI coach (optional)
          Off by default. When on, a short text summary of the match state (never screenshots) plus relevant guide excerpts is sent to the AI gateway you configure here. The rule-based coach keeps working unchanged. Setup guide ↗
          Stored only in this browser's local storage. Never logged or exported.
          Capture calibration
          Default: the complete 16:9 game window. Exclude window borders or letterboxing by setting the viewport as percentages of the selected source. Ultrawide game HUD layouts require further calibration.
          Runtime diagnostics
          Background capture, exclusive fullscreen and voice routing depend on your browser and OS. This build is calibrated on recorded 16:9 frames, not every HUD scale or game patch.
          
        
          
          
          ONE ENGINE. MANY GAMES.
          Matching lab
          Compose a perception pipeline, inspect every stage, and publish named fields. Game-specific coaching is a separate adapter.
          
          
          
            
          
            
          Edit a draft, then Apply profile to validate the graph and activate it.
          
          
          
          
          
            
          Pipeline definition
          No scripts are executed from profiles. Rust validates inputs, cycles, operations, templates and resources before replacing the active graph.
          
            
          
              
          Author a field
          Use a captured frame or load a screenshot. Region selection is free-aspect and can be as small as one pixel. Run successive frames to exercise temporal confirmation.
          
              
          Template assets
          Embeds a small PNG and adds a template-search stage. Restrict its search region and tune score/scale settings in the JSON.
          
            
          
          
          
          
          Published observations
          A score is detector similarity, not a calibrated probability. OCR scores remain unknown when the backend does not supply them. Missing/pending fields are never promoted to confirmed values.
          
          
          Stage inspector
          StageOperation / inputsStatusResultScoreTime
          
          
          Building blocks
          Crop and anchor regions → preprocess → OCR, icon classification, template search or color measurement → extract/parse → confidence gate → temporal confirmation → named outputs. Branches share upstream work; coalesce supplies fallbacks; when gates a branch on a boolean stage.
          Profiles support normalized, pixel and reference-resolution coordinates, corner/center anchors, custom Rust stages and replaceable OCR backends. The generic starters need region/template tuning for your game; they are not pretrained universal HUD recognizers.
